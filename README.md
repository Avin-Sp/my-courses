#  My Courses

A modern and responsive online learning platform built with React, Vite, and Tailwind CSS.

This project allows users to browse courses, search for specific topics, filter courses by category, and save their favorite courses through an interactive and user-friendly interface.

---

##  Features

*  Course Search
*  Category Filter
*  Favorites System
*  Responsive Design
*  Modern UI
*  Smooth Animations
